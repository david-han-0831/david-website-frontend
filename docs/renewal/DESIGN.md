# han-david.com DESIGN.md

2026-09-30 개정 · 히어로 = **라이브 데모 + 작업 벽** (시안 c6, 밝은 버전 확정). 키캡 히어로는 폐기.

## 히어로
- 가운데 질문 "무엇을 만들고 싶으세요?" + 입력창. 예시 칩 5개(병원 예약 앱, 쇼핑몰, 사내 관리 시스템, AI 영상 분석, 매장 POS).
- 입력하면 초안(제목·예상 기간·화면 수·만드는 것) + **비슷하게 만든 실제 작업**(data/projects.ts) 카드가 나온다. 지금은 `components/home/briefs.ts` 의 예시에서 키워드로 고르고, 없으면 "문의로 보내주세요" 안내. 나중에 Claude API 로 교체.
- "이 내용으로 문의하기" → 입력과 초안을 세션 저장소로 문의 폼 내용 칸에 채운다 (주소창에 남기지 않음).
- 뒤편: 실제 제품처럼 HTML 로 그린 작업 화면 5장이 원근으로 떠 있고 멀수록 흐리다 (`components/home/screens`). 화면 속 이름·숫자는 가상 데이터.
- 서체: 제목은 한글·라틴 모두 Wanted Sans 800, 본문 Pretendard. 색: 바탕 #EEF0F3, 글자 #111318, 보조 #5A5F6B, 코발트 #1E3CFF(주요 버튼).

## (이전) 키캡 콘셉트 기록

2026-09-30 · 레퍼런스: lusion.co · vgpu.sh · ricardochance.com (오브젝트 하나 + 절제) + incredibles.dev · darkroom.engineering (포지셔닝을 크게 말하는 타이포)

## 한 줄

**키캡 더미 하나가 주인공이고, 나머지는 크고 단정한 문장이다.**
개발자의 손끝에 있는 물건(키보드 키)이자 음악 전공자의 "건반"을 겹쳐, 이 사람에게만 맞는 오브젝트로 쓴다.
파란 Enter 키 = 새 프로젝트 시작. 한국 키보드의 한/영 키로 현지 디테일을 준다.

## 색 (4+1)

| 이름 | hex | 역할 |
|---|---|---|
| Aluminium | `#E9EBEF` | 페이지 바탕 — 알루미늄 키보드 케이스의 차가운 회색 (크림 아님) |
| Graphite | `#1B1C20` | 본문·제목 — 확실한 회색 (가짜 검정 #0B0B0B·#111 쓰지 않음) |
| Slate | `#5D6270` | 보조 문장 (Aluminium 위 대비 5.6:1) |
| Cobalt | `#1E3CFF` | **Enter 키와 문의 버튼에만.** 제목 강조에 쓰지 않는다 |
| Keycap white | `#FAFAFB` | 흰 키캡, 목록 행 호버 바탕 |

키캡 재질 색: 흰색 `#F4F4F6` · 알루미늄 `#C4C8D1` · 그래파이트 `#2A2C32` · 코발트 `#1E3CFF` (1개 — Enter).

## 서체 (두 벌)

| 역할 | 서체 | 규칙 |
|---|---|---|
| 제목 (라틴) | **Unbounded** 600 | 넓고 둥근 기하 서체 — 키캡의 둥근 사각형과 같은 형태. 자간 -0.02em, 행간 1.0 |
| 제목 (한글) | **Wanted Sans** 800 | 같은 기하 계열 한글. 자간 -0.03em, 행간 1.12 |
| 본문 | **Pretendard** 400/500 | 17px/1.65, 한 줄 34em 이하 |

- 대문자 라벨·고정폭 라벨·제목 위 eyebrow 없음. 섹션 제목이 곧 문장이다.
- 제목 안 한 단어만 색·굵기로 강조하지 않는다.
- 크기: 72 / 48 / 30 / 21 / 17 / 14 (px, 데스크탑 기준, clamp 로 축소)

## 모션 (세 곳만)

1. **첫 로드**: 키캡이 위에서 떨어져 쌓인다 (한 번). 마지막에 Enter 키가 떨어진다.
2. **커서**: 키캡 위를 지나면 그 키가 눌렸다 돌아온다. Enter 키를 누르면 문의 페이지로.
3. **작업 목록**: 행 위에 올리면 프로젝트 그림이 커서를 따라온다.

섹션마다 나타나는 페이드·슬라이드는 쓰지 않는다. 움직임 최소화 설정이면 키캡은 쌓인 상태로 정지.

## 문장

- 사용자 입장의 쉬운 말. 버튼은 일어나는 일 그대로: "프로젝트 문의하기".
- 기술 스택은 쉼표로 나열 (가운뎃점 연결 안 함).
- 성과는 데이터에 있는 숫자 그대로 (`data/projects.ts` outcome.result).
